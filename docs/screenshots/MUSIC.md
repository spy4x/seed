# Music under the admin panel video

`admin-video-music.opus` is the music `admin-video.ts` lays under the admin panel video on the
website's `/admin` page.

- Title: Calm Down
- Author: Rafael Archangel
- Album: Library Music Vol. 1 (2017)
- Source:
  https://freemusicarchive.org/music/Rafael_Archangel/Library_Music_Vol1/Rafael_Archangel_-_Library_Music_Vol1_-_07_Calm_Down
- Copy downloaded from Wikimedia Commons:
  https://commons.wikimedia.org/wiki/File:Rafael_Archangel_-_07_-_Calm_Down.ogg
- Licence: CC0 1.0 Universal, a public domain dedication
  (https://creativecommons.org/publicdomain/zero/1.0/). Both pages above state it. It allows
  commercial use with no attribution; this file names the source anyway.

The file here is the track's first 80 seconds, re-encoded to Opus at 96 kbit/s with no other
change. The recorder trims it to the video's length, lowers it by 5 dB and fades it in and out.
